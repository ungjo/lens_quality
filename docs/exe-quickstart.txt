렌즈 검사 프로그램 — 아이디어 공유용 데모

1. ZIP 파일을 마우스 오른쪽 버튼으로 누르고 [모두 압축 풀기]를 선택합니다.
2. 압축을 푼 LensQuality 폴더에서 LensQuality.exe를 더블클릭합니다.
3. 원본 Excel에는 포함된 샘플이 자동으로 선택됩니다.
4. 결과 저장 폴더를 확인하고 [검사 실행]을 누릅니다.
5. 샘플 결과: 전체 30개 / 합격 14개 / 불합격 16개 / 판정불가 0개.

Python, VSCode, 별도 데이터베이스 서버를 설치할 필요가 없습니다.
이 배포물은 Windows 64비트용입니다.
LensQuality.exe와 _internal 폴더는 반드시 함께 보관하세요.
ZIP 안에서 바로 실행하지 말고 먼저 모두 압축을 풀어 주세요.

기본 저장 위치:
C:\Users\사용자이름\LensQuality\results
사용자 폴더 위치는 Windows 계정 설정에 따라 다를 수 있습니다.
GUI의 [폴더 선택]으로 다른 위치를 지정할 수 있습니다.

[검사 실행] 후 생성되는 파일:
- lens_quality.db: 원본 측정값, 기준, 검사 결과, 항목 상세
- lens_inspection_result.xlsx: 검사 결과 Excel
같은 저장 폴더에서 다시 검사하면 이전 결과를 갱신합니다.

[저장된 DB 열기]는 기존 결과 조회 기능이며 새 검사를 시작하지 않습니다.
[SQL 내보내기]를 눌러 원하는 위치에 lens_quality.sql을 저장할 수 있습니다.
Excel이 없어도 검사, GUI 표 조회, Excel 파일 저장이 가능합니다.
[결과 Excel 열기]에는 .xlsx를 열 수 있는 연결 프로그램이 필요합니다.
